# Лабораторна робота №2

## Завдання: Розрізання пирога з родзинками

Написати програму мовою Ruby, яка приймає на вхід прямокутний пиріг (`cake`), представлений у вигляді текстового рядка з кількома рядками, що відповідають рядкам пирога.

Пиріг складається з:
- `.` - порожня клітинка;
- `o` - родзинка.

Необхідно розрізати пиріг на `n` прямокутних шматочків так, щоб виконувалися такі умови:

1. Кожен шматочок містить рівно одну родзинку.
2. Усі шматочки мають однакову площу.
3. Кожен шматочок має прямокутну форму, але його ширина та висота можуть відрізнятися від інших.
4. Усі шматочки разом повинні утворювати початковий пиріг без пропусків і перекриттів.
5. Кількість шматочків `n` дорівнює кількості родзинок у пирозі та не передається як окремий аргумент.
6. Кількість родзинок більша за 1 і менша за 10.
7. Якщо існує декілька правильних варіантів розрізання, потрібно вибрати той, у якого перший шматочок має найбільшу ширину.

## Алгоритм розв'язання

Для пошуку правильного розрізання використовується рекурсивний алгоритм із поверненням (backtracking).

Програма визначає кількість родзинок і площу одного шматочка, після чого послідовно знаходить вільні клітинки та перевіряє можливі прямокутники. Якщо обраний варіант не дозволяє завершити розрізання, алгоритм повертається до попереднього стану й пробує інший.

Можливі розміри шматочків перевіряються від найбільшої ширини до найменшої.

## Приклад

Початковий пиріг:

```text
.o......
......o.
....o...
..o.....
```

Пиріг містить 4 родзинки, тому його потрібно розділити на 4 прямокутні шматочки однакової площі.

Результат:

```ruby
[
  ".o......",
  "......o.",
  "....o...",
  "..o....."
]
```

У цьому випадку кожен шматочок має ширину 8 клітинок, висоту 1 клітинку, площу 8 клітинок і містить рівно одну родзинку.

Такий варіант відповідає умові вибору найбільшої ширини першого шматочка.

## Результат роботи програми

Метод `cut_cake(cake)` повертає масив прямокутних шматочків пирога, які відповідають усім зазначеним умовам.

Кожен елемент масиву є рядком, який представляє окремий шматочок. Якщо правильне розрізання неможливе або вхідні дані некоректні, метод повертає порожній масив `[]`.

## Запуск програми

Перебуваючи в кореневій папці репозиторію, запустіть програму командою:

```bash
ruby lab02/main.rb
```

Після запуску вставте пиріг цілком. Для завершення введення натисніть Enter на порожньому рядку.

Програма виведе знайдені прямокутні шматочки або повідомлення про неможливість розрізання.
