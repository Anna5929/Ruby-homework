# Практичне завдання - Облік товарів (Inventory)

## Опис завдання

Розробити програму мовою Ruby для обчислення загальної вартості товарів на основі даних із JSON-файлу.

Програма повинна зчитувати інформацію про назву, ціну в копійках і кількість кожного товару, перевіряти коректність вхідних даних та обчислювати загальну вартість у гривнях.

Також необхідно реалізувати обробку помилок читання файлу, некоректного синтаксису JSON і недопустимих значень.

## Функціональні можливості

- Зчитування списку товарів із файлу `data/products.json`.
- Перетворення JSON-даних на структури Ruby.
- Перевірка кореневої структури та обов'язкових полів кожного товару.
- Перевірка непорожньої назви, невід'ємної ціни та кількості.
- Обробка даних за принципом «усе або помилка» із зазначенням номера некоректного запису.
- Обчислення загальної вартості товарів у копійках.
- Виведення результату у форматі `262.50 грн`.
- Обробка помилок із відповідними кодами завершення програми.

## Технічні вимоги

- Використання модуля `Inventory` з методами `load` і `total`.
- Створення власних класів винятків `Inventory::Error`, `Inventory::ReadError` та `Inventory::DataError`.
- Використання стандартної бібліотеки `json`.
- Розділення логіки програми та скрипта запуску.
- Перетворення `Errno::ENOENT` на `ReadError`, а `JSON::ParserError` - на `DataError`.
- Виведення повідомлень про помилки в `stderr` через `warn`.
- Завершення програми з кодом `0` у разі успіху, `2` для `DataError` та `3` для `ReadError`.
- Виконання грошових обчислень у цілих копійках без використання `Float`.

## Результати тестування

| Тестовий сценарій | Результат | Код завершення |
|---|---|---|
| Коректні вхідні дані | `262.50 грн` | `0` |
| Від'ємне значення `quantity` | Повідомлення про некоректну кількість у записі 2 | `2` |
| Синтаксична помилка JSON | Повідомлення про некоректний JSON | `2` |
| Неіснуючий файл | Повідомлення про помилку читання | `3` |

Усі чотири сценарії перевірено. Програма правильно обчислює загальну вартість товарів та обробляє передбачені завданням помилки.

## Запуск програми

Перебуваючи в кореневій папці репозиторію, виконайте команду:

```bash
ruby Practical_Test/Inventory/bin/report.rb
```

Для коректних тестових даних програма виведе:

```text
262.50 грн
```

За потреби можна вказати шлях до іншого JSON-файлу як аргумент командного рядка:

```bash
ruby Practical_Test/Inventory/bin/report.rb path/to/products.json
```

Для запуску потрібен встановлений Ruby. Додаткові сторонні бібліотеки не використовуються.
