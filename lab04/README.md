# Лабораторна робота №4 - Гра «Морський бій»

## Опис завдання

Розробити консольну гру «Морський бій» з ігровим полем 10×10, у якій користувач змагається з комп'ютером.

Кораблі розміщуються автоматично, а гравець і комп'ютер по черзі виконують постріли до перемоги одного з учасників.

## Правила гри

1. Кожен учасник має поле 10×10 та флот із 10 кораблів.
2. Флот складається з одного чотирипалубного, двох трипалубних, трьох двопалубних і чотирьох однопалубних кораблів.
3. Кораблі не можуть перетинатися або торкатися один одного, зокрема по діагоналі.
4. Гравець і комп'ютер виконують постріли по черзі.
5. Для пострілу необхідно ввести координати від A1 до J10.
6. Повторні постріли в одну клітинку заборонені.
7. Перемагає той, хто першим знищить усі кораблі суперника.

## Функціональні можливості

- Відображення ігрових полів у консолі.
- Автоматичне випадкове розміщення кораблів.
- Приховування кораблів комп'ютера.
- Введення та перевірка координат пострілу.
- Визначення промаху, влучання та знищення корабля.
- Комп'ютерний суперник із випадковим вибором координат без повторень.
- Обробка некоректного введення та повторних пострілів.
- Автоматичне визначення переможця.
- Можливість дострокового завершення гри.

## Додаткові можливості

- Головне меню з можливістю почати нову гру, переглянути правила та вийти з програми.
- Статистика перемог і поразок протягом роботи програми.
- Відображення знищених кораблів окремим символом.
- Перегляд розташування кораблів обох учасників після завершення гри.

- Використання модулів, `require` та `require_relative`.

## Запуск програми

Перебуваючи в кореневій папці репозиторію, запустіть гру командою:

```bash
ruby lab04/main.rb
```

Після запуску програма відобразить головне меню з можливістю почати нову гру, переглянути правила, статистику або завершити роботу.

Під час гри необхідно вводити координати пострілів у форматі `A1`, `B5` або `J10`. Для дострокового повернення до головного меню введіть `0`.
