## Як запустити програму

Для виконання лабораторних робіт необхідно встановити Ruby.

**Перевірка версії Ruby:**

```bash
ruby --version
```

Для запуску програм необхідно перейти в директорію відповідної лабораторної роботи та виконати команду:

```bash
ruby назва_файлу.rb
```

Детальні інструкції та конкретні команди запуску наведено у файлі `README.md` кожної лабораторної роботи.
