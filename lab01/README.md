# Homework 1

## Task 1 - Word Statistics

Користувач вводить рядок тексту.

Потрібно реалізувати метод `word_stats(text)`, який:
- підраховує кількість слів;
- знаходить найдовше слово;
- підраховує кількість унікальних слів без урахування регістру.

Приклад:

`Ruby is fun and ruby is powerful`

Результат:
- слів: 7;
- найдовше слово: `powerful`;
- унікальних слів: 5.

## Task 2 - Guess the Number

Комп'ютер загадує число від 1 до 100.

Користувач вводить припущення, а програма підказує:
- більше;
- менше;
- вгадано.

Гра триває, поки користувач не вгадає число.

Додатково:
- підраховувати кількість спроб;
- реалізувати метод `play_game`.

## Task 3 - Rock, Paper, Scissors

Користувач і комп'ютер обирають:
- камінь;
- ножиці;
- папір.

Програма повинна визначити результат раунду:
- Ви перемогли!
- Комп'ютер переміг!
- Нічия!

Протягом гри необхідно вести статистику:
- кількість перемог користувача;
- кількість перемог комп'ютера;
- кількість нічиїх;
- загальну кількість зіграних раундів.

Після кожного раунду виводити поточну статистику.
