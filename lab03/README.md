# Лабораторна робота №3 - Гра «Судоку»

## Опис завдання

Розробити консольну гру «Судоку» з ігровим полем 4×4, розділеним на чотири блоки 2×2.

Частина клітинок містить початкові числа, а решту повинен заповнити гравець.

## Правила гри

1. У кожному рядку мають бути числа від 1 до 4 без повторень.
2. У кожному стовпці числа не повинні повторюватися.
3. У кожному блоці 2×2 числа не повинні повторюватися.
4. Початкові числа змінювати заборонено.
5. Перемога досягається після правильного заповнення всього поля.

## Функціональні можливості

- Відображення ігрового поля в консолі.
- Введення номера рядка, стовпця та числа.
- Перевірка правильності ходів.
- Захист початкових чисел від змін.
- Обробка некоректного введення.
- Перевірка перемоги після кожного ходу.
- Можливість дострокового завершення гри.

## Додаткові можливості 

- Декілька рівнів складності.
- Скасування останнього ходу.
- Підказки для гравця.
- Статистика ходів і помилок.
- Ігрове поле 9×9.

## Технічні вимоги

- Використання двовимірного масиву для ігрового поля.
- Розділення логіки програми на окремі методи.
- Консольне введення та виведення.
- Відсутність сторонніх бібліотек.
- Початкове поле з коректним розв'язком.

## Запуск програми

Перебуваючи в кореневій папці репозиторію, запустіть гру командою:

```bash
ruby lab03/main.rb
```

Після запуску програма запропонує вибрати розмір поля: 4×4 або 9×9. Для Судоку 4×4 також доступний вибір рівня складності.
